beacon follows semantic versioning, plus the extra rules in the [determinism contract](../../guarantees/determinism/): **patch releases never change block output, error messages included.** Each release lists *Behaviour changes* separately: any input whose output differs from the previous release.

The canonical changelog is [`CHANGELOG.md`](https://github.com/IND-Anshuman/beacon/blob/main/CHANGELOG.md) in the repository; releases are tagged on [GitHub](https://github.com/IND-Anshuman/beacon/releases).

## 1.0.0 · unreleased

v1.0 takes the core cross-language. The pure-Rust blocks are now a standalone, publishable crate, and the same code ships to JavaScript/TypeScript via WebAssembly — proven byte-identical to the Python package by a shared corpus. No existing block output, error code or message changed.

### Added

- **`beacon-core` crate** — the pure-Rust blocks, dry-run-publishable to crates.io (no PyO3). The repository is now a Cargo workspace: `beacon-core`, `beacon-python` (the `llm-beacon` wheels), `beacon-wasm` (the playground) and `beacon-js` (the npm package).
- **`parse_partial`** — parse an incomplete JSON prefix, as it streams, into the best value so far, reporting `complete` and `consumed`. In `beacon`, `beacon.aio`, the CLI (`beacon partial`) and JavaScript.
- **`extract_citations`** — numeric markers (`[1]`, `[1, 2]`, `[1-3]`), Markdown footnotes (`[^id]`) and inline URLs, as ordered spans.
- **`detect_injection`** / **`scan_arguments`** — deterministic flag-only heuristics (SQL injection, shell metacharacters, path traversal, prompt-injection phrases) over text and over tool-call arguments. Not a security guarantee.
- **`llm-beacon` on npm** — the full core compiled to WebAssembly with wasm-bindgen and idiomatic TypeScript types; runs in Node (ESM) and the browser.
- A cross-language golden corpus asserting byte-identical output between the Python and JavaScript builds.

## 0.1.0 · unreleased

The first release, published on PyPI as `llm-beacon` (import name `beacon`).

### Added

- **Blocks**, implemented in Rust via PyO3 0.30: `template`, `template_variables`, `extract_json`, `extract_json_detailed`, `parse_tool_call`, `parse_tool_calls`, `validate_schema`, `schema_errors`, `normalize`, `hash_content`, `redact`, `detect_pii`, `retry.classify`, `retry.backoff_delay`, `retry.call`.
- **Composition**: `Pipeline` and `Block`, with content-hash traces.
- **Snapshot testing**: `assert_snapshot`, the pytest `snapshot` fixture, `--beacon-snapshot`, and `python -m beacon.snapshots update|check`.
- **Integrations**: OpenAI SDK, LangChain, LlamaIndex, Pydantic AI, DSPy.
- **Packaging**: abi3 wheels for CPython 3.10+.
